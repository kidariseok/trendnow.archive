# trendnow.archive

← [instagram.archive](../../README.md)

서울의 전시, 바, 카페를 직접 다녀와 찍은 사진으로 소개하는 계정입니다. 사진은 모두 직접 촬영합니다.

## 콘셉트

- **다루는 것**: 서울 전시, 바, 카페, 베이커리 같은 가 볼 만한 공간
- **관점**: 직접 가서 오래 머문 사람의 기록. 정보보다 그 자리의 장면이 먼저 나온다.
- **분위기**: 차분한 에디토리얼. 사진이 주인공이고 글자는 절제한다.

## 요청 방식

이런 재료를 주면 게시물 하나를 만듭니다.

- 직접 찍은 사진 (보통 9–10장 분량)
- 장소 이름, 그날 먹거나 본 것, 기억에 남은 한 장면
- 예약 게시가 필요하면 날짜와 시간(KST)

영업시간, 가격, 주차 같은 사실 정보는 네이버 플레이스 등 공식 출처로 확인하고 캡션에 출처를 밝힙니다.

## 슬라이드 디자인

- **규격**: 1080×1350 JPG, 9–10장 캐러셀
- **구성**: 표지 → 이름이나 주제의 뜻 → 사진 슬라이드 → 인용 한 장(‘오늘의 문장’, ‘이날의 기록’) → 방문 전 체크리스트 → 위치·시간·가격 정보
- **상단 고정 요소**: 왼쪽에 이탤릭 세리프 워드마크 `trendnow.archive`, 오른쪽에 `01 / 09` 형식의 장 번호
- **폰트**
  - 워드마크·인용부호: 이탤릭 세리프
  - 한글 제목·본문: 깔끔한 산세리프(제목은 크게, 본문은 가볍게)
  - 위의 폰트 이름은 기존 슬라이드에서 본 인상으로 정리한 것입니다. 실제 쓰는 폰트 이름이 있으면 `profile.json`에 적어 주세요.
- **색**: 사진 위에서는 흰 글자, 작은 라벨은 장소 분위기에 맞춘 포인트색(예: 바는 앰버). 글만 있는 장은 게시물마다 한 가지 단색 배경(예: 서촌스코프는 베리 레드).
- **표지**: 사진 전면 + 아래쪽에 작은 라벨, 두 줄 제목, 짧은 가로선, 영문 장소명과 주소

## 캡션 규칙

1. `‘한 줄 훅’` + 이모지 1개
2. 검색용 소개 한두 문장(지역 + 장르 키워드, 장소 이름)
3. 장면 묘사 두 단락
4. Q&A 2–3개(기간·영업시간, 요금·주차·메뉴 등). 출처 표기.
5. `📍 장소 · 주소`
6. `📸 직접 다녀와 찍은 사진 · trendnow.archive` (전시는 작품 저작권 표기 추가)
7. 해시태그 4개 + `#trendnow`
