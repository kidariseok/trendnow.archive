# Figma 카드 파일

← [tech.archive](../README.md) · [오케스트레이션](orchestration.md)

카드 이미지를 만드는 Figma 파일 정보입니다. **지휘자만** 고칩니다. 파일은 하나만 쓰고 섹터마다 페이지를 나눕니다.

| 항목 | 값 |
|---|---|
| 파일 이름 | tech.archive cards |
| 파일 키 · URL | (시범 섹터에서 템플릿을 만들 때 기록) |
| 규격 | 1080×1350 프레임, JPG 내보내기 |
| 템플릿 페이지 | `Template` |
| 섹터 페이지 | `<NN>-<slug>` |

디자인 규칙(폰트, 색, 장 구성)은 시범 섹터를 만들며 정해 [tech 계정 README](../README.md)의 "슬라이드 디자인 · 캡션 규칙"에 옮깁니다(로드맵 T07).
