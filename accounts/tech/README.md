# tech.archive (임시 이름)

← [instagram.archive](../../README.md)

쏟아지는 AI·테크 뉴스 중 중요한 것을 골라, 무슨 일이 있었는지뿐 아니라 왜 중요한지와 앞으로 무엇이 달라지는지까지 짧은 인스타그램 콘텐츠로 해설하는 계정입니다.

> 폴더 이름 `tech`는 바뀌지 않습니다. 계정 이름은 `profile.json`의 `handle`에만 적혀 있어서, 이름이 바뀌어도 기획 문서와 게시물 이력은 그대로 유지됩니다.

## 모든 게시물이 답할 세 가지

1. **What happened?** 실제로 무슨 일이 발생했는가
2. **Why does it matter?** 독자와 산업에 어떤 의미가 있는가
3. **What's next?** 앞으로 무엇을 주목해야 하는가

| 축 | 다루는 것 | 운영 |

| 02 AI 기술과 연구 | 논문, 벤치마크, 추론·에이전트·멀티모달의 발전과 한계 | 초기 중심 |

| 04 실용적인 AI 활용 | 새 도구, 업무 적용 사례, 생산성 활용법 | 이후 별도 시리즈 |
