# 자료집 검수

검수는 고치는 일이 아니라 **판정을 남기는 일**이다. 무엇이 왜 틀렸는지 기록으로 남아야 분석가가 정확히 고치고, 같은 실수가 다음 섹터에서 줄어든다.

## 기준

- `accounts/tech/planning/analysis-workflow.md`의 「통과 조건」과 「출처 표기 원칙」
- `accounts/tech/planning/orchestration.md`의 「섹터 완료 조건」

## 섹터마다

1. `dossier.md`의 수치·날짜·인용을 모두 뽑는다.
2. 적힌 출처 URL을 연다. curl로 열리면 curl로. 안 열리면 "확인 불가 · Chrome 재조사 필요".
   - Firecrawl은 **웨이브 전체에서 2크레딧 이하**, 게시물 각도의 핵심 근거가 되는 수치에만.
3. 비교 기준을 놓치지 않는다: 퍼센트와 퍼센트포인트, 연환산과 실제, 회사 자체 측정과 독립 측정, 시뮬레이션과 실제.
4. 5절 분석이 근거를 넘어서는 문장, 6절 각도가 기대는 근거가 "확인 불가"인 경우를 찾는다.
5. 섹터 완료 조건을 하나씩 체크한다(`wc -l brief.md`로 30줄 이하 확인 포함).

## review.md 형식

```
# <NN> <섹터> — 검수
판정: 통과 / 수정 필요

| # | 주장 | dossier 값 | 원문 값 | 판정 (일치·다름·확인 불가) | 출처 URL |

## 섹터 완료 조건
- [ ] ...

## 수정 필요 사항
1.

Firecrawl 사용: N크레딧
```

"확인 불가"가 핵심 근거에 있으면 판정은 "수정 필요"다. 확인하지 못한 것을 통과로 세면 검수의 의미가 없다.

## 카드 검수 (카드 문안·이미지)

자료집이 아니라 **카드가 자료집을 정확히 옮겼는지** 본다. 원문을 다시 찾지 않는다. 기준은 통과한 `dossier.md`다. 자료집 자체의 오류는 이미 `review.md`에서 걸렀다.

1. `card/slides.md`와 `card/caption.txt`의 모든 숫자·고유명사·인용을 뽑아 `dossier.md`의 같은 칸과 대조한다. 반올림, 단위 변경, 비교 기준 누락(%/%p, 자체 발표인데 독립 측정처럼 쓴 문장)을 찾는다.
2. 자료집에 없는 새 사실·추정·전망이 문안에 있는지 찾는다. 있으면 "근거 없음"이다.
3. 5절 "한계와 불확실성"이 카드에 남아 있는지 본다. 빠졌으면 "수정 필요"다.
4. `card/NN.jpg`를 한 장씩 직접 열어 본다(Read로 이미지 열기). 이미지 속 글자가 `slides.md`와 같은지, 글자 잘림·넘침, 장 번호, 출처 장의 URL·날짜를 확인한다.
5. 크기 1080×1350, 장 수가 `slides.md`와 같은지 확인한다.

### card-review.md 형식

```
# <NN> <섹터> — 카드 검수
판정: 통과 / 수정 필요  (문안 수정 / 디자인 수정을 구분)

| # | 장 | 카드 값 | dossier 값 | 판정 (일치·다름·근거 없음) |

## 이미지 확인
- 01.jpg: ...

## 수정 필요 사항
1. (문안: card-writer / 디자인: card-designer)
```

수정 필요가 문안이면 `card-writer`, 모양이면 `card-designer`가 고친다. 어느 쪽인지 반드시 적는다.

## 하지 말 것

- `dossier.md`, `brief.md`, `chrome-findings.md`, `slides.md`, `caption.txt`, 이미지를 고치지 않는다.
- 다른 섹터의 결론을 근거로 이 섹터를 판정하지 않는다.
